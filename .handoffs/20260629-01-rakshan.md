### Step 1 — Backend: finish Part C (COST) — the meaty one
1. **`services/translate.py`**: add an optional `meter` param (same minimal-churn pattern as `cache=`). On the OpenRouter path, record `usage.prompt_tokens`/`completion_tokens` (always returned) and `usage.cost` if present; else compute `cost = tokens × price` from the `/models` catalog. Sarvam → `chars × 0.002 INR` (convert to USD via a config `inr_per_usd`, ~83). YouTube → 0. A `CostMeter` = `{provider, model, prompt_tokens, completion_tokens, cost_usd, calls}`.

## Gotchas / blockers
- **Shared-session concurrency**: any per-segment DB I/O (cache, cost meter) MUST use a fresh `AsyncSessionLocal()`, never the shared video `session`. The proven template is `scripts/translate_segments.py`.
- **SQLite write locks**: keep `video_concurrency` modest (2-3) on dev SQLite; Postgres (prod) is fine.
- **`force`** ⇒ pass `read_cache=False`; **pre-built glossary** ⇒ pass `apply_glossary=False`. Never overwrite `en_final` when `en_human` is set.
- **Cost currency**: OpenRouter USD; Sarvam INR → convert with a config `inr_per_usd`. Store `cost_usd` uniformly. If OpenRouter `usage.cost` present, prefer it.
- Minor: single `/batch/translate` endpoint default model is stale `google/gemma-3-27b-it` vs config `claude-haiku-4.5`; the *runner* uses config. Align if you touch it.
