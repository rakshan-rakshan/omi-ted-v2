## TOMORROW — install Coolify (multi-app hosting + HTTPS)
**Why**: run more apps on the box (~6 GB RAM / 55 GB disk free) and get real HTTPS. **Coolify is free** (self-hosted, open source); "Coolify Cloud" (~$5–10/mo) is optional and not needed.

**Two snags to resolve first**:
1. Coolify's dashboard defaults to **port 8000** = omi-ted's live backend port → conflict.
2. TLS needs a **domain** → 95.217.178.38. ← **DECISION PENDING** (have one / register ~$10-yr / IP-only).

**Recommended path (with a domain)** — one clean migration solves both snags:
1. Run `add_swap.sh` (2 GB swap).
2. DNS: `coolify.<domain>` + `api.<domain>` → 95.217.178.38.
3. Install Coolify: `curl -fsSL https://cdn.coollabs.io/coolify/install.sh | bash` (Traefik on 80/443 + dashboard).
4. **Migrate omi-ted behind Coolify's Traefik** → `https://api.<domain>` with auto Let's Encrypt TLS; this stops it binding host:8000, freeing 8000 for the Coolify dashboard.
5. Update Vercel env `BACKEND_URL` → `https://api.<domain>`, redeploy (auth key unchanged).
6. Deploy future apps from the Coolify dashboard.

**Without a domain**: install Coolify on a non-8000 port over `http://IP`, leave omi-ted untouched on :8000, defer HTTPS.
